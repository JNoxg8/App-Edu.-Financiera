# Zenfi API

Backend de la aplicación de educación financiera **Zenfi** (Universidad Central).

Proyecto base generado con Quarkus. La configuración del proyecto (dependencias,
`application.yml`, variables de entorno) está en la rama `develop`, y cada módulo
se desarrolla en su propia rama `feature/...`.

## Ejecución

```shell
mvnw.cmd quarkus:dev
```
